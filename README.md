# 安全库存波动看板 Safety Stock Volatility Dashboard

上传每个季度的库存 CSV，看哪些料号的需求和交期不稳，以及安全库存随季度怎么变。

A single-file, offline HTML dashboard for reviewing safety stock volatility across quarters. No server, no dependencies, no build step. Your data is processed locally in the browser and is never uploaded.

![截图](docs/screenshot.png)

在线体验（启用 GitHub Pages 后可用）：` https://liluyao5075-svg.github.io/safety-stock-volatility-dashboard/

## 功能

- 一次上传多个季度的 CSV，也可以直接把文件拖进页面，随时追加或替换某个季度
- 汇总指标：料号数、最新季安全库存合计和金额、平均需求波动、平均交期波动，以及较上季的变化
- 波动矩阵：横轴是需求波动，纵轴是交期波动，圆圈大小是安全库存；安全库存在季度之间波动最大的前 5 个料号标为红色
- 点击圆圈：显示这个料号每个季度各自的位置，并展示每季 8 周出库量折线、每季 6 笔交货对比 EDI 通知交期的柱状图
- 全部料号明细表：可排序，可按供应商、ABC 类别、料号筛选
- 完全离线：不依赖任何外部库、字体或网络请求

## 快速开始

1. 下载 `index.html`，双击用 Chrome 或 Edge 打开
2. 点右上角"选择 CSV 文件"，一次选中 `sample_data/` 里的三个文件（也可以用你自己的数据）
3. 点矩阵里的圆圈，或表格里的某一行，查看详情

## 数据格式

每个季度一个 CSV，每行一个料号。必须包含以下列（列名区分大小写）：

| 列名 | 含义 |
|---|---|
| `Quarter` | 季度标签，如 Q1。同一个文件里出现多个季度也可以 |
| `Part_No` | 料号，同一季度内唯一 |
| `Part_Desc` | 料号描述 |
| `Supplier` | 供应商 |
| `Region` | 供应商所在地区 |
| `ABC_Class` | ABC 分类 |
| `Unit_Cost_EUR` | 单价（欧元），用于计算安全库存金额 |
| `LT_obs1_days` 至 `LT_obs6_days` | 最近 6 笔实际交货的天数 |
| `EDI_LeadTime_days` | 供应商通知的交期（天），填 0 表示没有通知 |
| `WH_Demand_Wk1_units` 至 `WH_Demand_Wk8_units` | 最近 8 周每周实际出库量 |

- 自动识别逗号、分号、制表符分隔，也支持小数逗号（如 `24,75`）
- 优先按 UTF-8 读取，失败时会尝试 GB18030，并给出提示
- 缺少必需列、含负数或缺失数值的行会被跳过，页面顶部会提示

## 计算方法

**波动**用变异系数表示：标准差 ÷ 均值（样本标准差，n-1）。需求波动取 8 周出库量，交期波动取 6 笔历史交货天数。

**交期取值**：比较 6 笔历史交期的均值与 EDI 通知的交期，相差超过历史均值的 20% 时，改用 EDI 交期作为交期均值，并把历史标准差放大 1.2 倍；否则沿用历史实绩。

**安全库存**：

```
SS = Z × √( L × σd² + D² × σL² )
```

- L：交期均值（天）；σL：交期标准差（天）
- D、σd：每日需求的均值和标准差
- Z = 1.65，对应约 95% 的服务水平
- 交期完全稳定（σL = 0）时，公式就是常见的 Z × σ × √L

数据里的需求是每周的，所以先换算成每日：日均 = 周均 ÷ 7，日标准差 = 周标准差 ÷ √7。

**安全库存波动**：一个料号各季度安全库存的变异系数，用来标红前 5 名。

**矩阵**：位置是已加载各季度需求波动、交期波动的平均值，圆圈大小是各季度安全库存的平均值。

上面的参数在 `index.html` 脚本开头，可以直接修改：

```js
var Z=1.65, EDI_TOL=0.2, EDI_STD_UP=1.2, DAYS=7;
```

## 假设与限制

- 公式是一个通用的参考实现，不代表任何公司的官方方法，用于实际决策前请结合自己的业务核对
- 日标准差 = 周标准差 ÷ √7，假设每天的需求相互独立，一周按 7 天算
- EDI 覆盖规则（20%、1.2 倍）是经验性设定，不是行业标准
- 每季度只用 8 周需求和 6 笔交期，样本较小
- 不保存数据：关闭或刷新页面后需要重新上传
- 主要在 Chromium 内核浏览器里测试过，其他浏览器未做完整测试
